01 Hardware Controls & Status Bar Architecture

The Smart Parcel Dropbox is operated via two front-mounted physical tactile push buttons, an optical barcode/QR code laser scanner window, and internal sensors.

Physical Button Mapping

BTN 1 (Left • Cyan Pill): GPIO 40 — Primary action button: triggers "DROP-OFF", starts "Begin Setup", and performs "RETRY" during failed scans.

BTN 2 (Right • Red Pill): GPIO 2 — Secondary/Exit button: triggers "PICK-UP", "CANCEL / EXIT", and returns from scanner mode.

Centered Telemetry Status Bar Breakdown (Zero-Text Sleek)

The top 26 pixels of all operative screens host a centered status cluster that delivers vital system health at a single glance with zero flickering:

1. Wi-Fi Signal Bars (Left, 4 bars): Green = Connected to local Wi-Fi router; Red = Wi-Fi disconnected or scanning.

2. Cloud Backend Socket (Center Cloud): Green = Secure WebSocket connected to Cloud Backend; Red = Backend unreachable.

3. Solenoid Locks Status (Right Padlock): Slate Closed = All doors securely locked; Amber Open = Top hopper lid or lower door currently unlocked.

02 Idle & Standby Workflow

When awaiting couriers or recipients, the device rests in standby or ambient lockscreen mode.

IDLE STANDBY Home Screen (Dual Vertical Cards)

Features twin Tesla-inspired cards with high-contrast accent borders. Clearly distinguishes Drop-Off (Cyan) from Pick-Up (Crimson).

Left Card ActionPress BTN 1 to initiate courier drop-off sequence.
Right Card ActionPress BTN 2 to initiate recipient package pick-up sequence.
Auto-Lock TimeoutTransitions to Robot Eye Lockscreen after 30 seconds of inactivity.
Admin MenuLong-press BTN 1 for 2.0s to open the Settings Menu.

POWER SAVER Ambient Robot Eye Lockscreen

Displays animated, friendly cybernetic eyes with blinking and emotion cycles. Minimizes backlight power while signaling that the box is actively monitoring.

Visual FeedbackCyan robotic pill eyes with realistic blinking and expressions.
Wake-up ActionPress either BTN 1 or BTN 2 to instantly wake up to Home.
Sensor Wake-upApproaching motion or laser trigger immediately restores Home.

04 Recipient Package Pick-Up Workflow

The retrieval workflow for the box owner or authorized household member to retrieve all collected parcels from the bottom compartment.

RETRIEVAL Pickup Compartment Unlocked

Triggered when recipient presses BTN 2 (Pick-Up) and scans their personal pickup pass, or taps "Unlock Pickup Door" inside the Mobile App.

Solenoid ActionLower compartment lock unlatches (Hi-Z/GND mode).

05 Hardware Setup & Provisioning Workflow

On first boot out of the box (or after a factory reset), the dropbox guides the user through Bluetooth Wi-Fi onboarding and Cloud Account pairing.

STEP 1 / 4 Setup Required (First Boot)

Displays a prominent 8-tooth mechanical gear icon in gold with a glowing cyan "Begin Setup" button. Informs user to pair the hardware with their Mobile App.

User ActionPress BTN 1 to start Bluetooth Wi-Fi setup.
AlternativeOpen Mobile App and select "Add New Dropbox".

STEP 2 / 4 Bluetooth Wi-Fi Provisioning

High-contrast pure white screen with clean QR code plate. Phone camera scans this QR code to securely pair via BLE and transmit Wi-Fi SSID & password.

QR PayloadEncrypted string SPDBLE:<MAC>:<SETUP_SECRET>.
High-ContrastWhite background eliminates LCD backlight moiré on phone cameras.
TimeoutActive for 2 minutes; press BTN 2 to cancel.

STEP 3 / 4 Cloud Account Registration (QR & 6-Digit PIN)

Once Wi-Fi connects, the device contacts the Cloud Backend and receives a secure token. Displays a large QR code and human-readable 6-digit Code.

App PairingScan QR with app OR type the bold 6-digit PIN (e.g. 482-913).
Live CountdownDynamic pill updates: Expires in 58s - BTN 2 to cancel.
Cancel ActionPress BTN 2 anytime to cancel and return to Setup Prompt.

STEP 4 / 4 Device Paired Successfully

Emerald green unified modal card with checkmark badge confirming registration. The pairing token is saved to Non-Volatile Flash Storage (NVS).

NVS StoragePersists registered: true permanently across reboots.
TransitionAuto-transitions to operative Home Screen in 1.5 seconds.

06 Alerts, Errors & Security Modals

All system alerts, barcode rejections, timeouts, and safety safeguards are unified in the Tesla Sleek modal format.

SECURITY ALERT Scan Rejected (Invalid Tracking ID)

Unified crimson red card with circular 'X' badge. Triggers when a courier scans a tracking barcode not registered in the delivery log or rejected by the cloud.

Security RuleDropbox remains locked; solenoid is NOT energized.
Audio CueDouble low error buzz pattern.
Auto-ActionDwells for 2.0s then returns to Scanner for another attempt.

EXCEEDED Scan Failed (3 Attempts Exceeded)

Displays when 3 consecutive invalid barcodes are scanned. Halts laser scanner to protect battery and hardware.

Left OptionPress BTN 1 (Cyan) to Retry scanner with fresh attempt counter.
Right OptionPress BTN 2 (Red) to Exit and abort to Home Screen.

SENSOR WARNING Drop Failed (No Parcel Detected)

Anti-fraud protection: if the top door was opened and closed, but ultrasonic sensor detects no change in bin volume (no package dropped), this alert appears.

Integrity SafeguardPackage is NOT marked as delivered in backend or courier log.
NotificationAlert sent to Mobile App informing owner of empty drop cycle.

NETWORK ALERT No Server (Device Offline)

Displays when Wi-Fi is lost or Cloud server is unreachable during an operation.

Option 1Press BTN 1 (Cyan) to trigger immediate Wi-Fi reconnect retry.
Option 2Press BTN 2 (Red) to launch BLE Wi-Fi provisioning to reconfigure network.
